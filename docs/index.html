Who this course is for

Admins and security staff who set or review sandbox policy. Some learners can already run a CLI and need the judgment. Others can already judge risk and need the commands. The two lessons serve both.

The course assumes its learning plan has already installed sbx and created one sandbox that uses the Claude Code kit.

How this course stays current

Each claim in the course is traced to a heading in Docker's documentation or to a result tested on a real machine. When the documentation changes, a workflow judges whether the change affects the course, drafts a revision of the affected sections, and opens a pull request. A subject-matter expert reviews every pull request before anything is published.

The revision history is in the refresh-log folder of this course's repository.
